# 한잔로스터리 코드 지도

코드 안에 `// ===== [구역 이름] =====` 표시가 있어요.
오류가 나면 아래 표에서 증상을 찾고, "○○ 부분에서 오류가 났어요"라고 구역 이름으로 말하면 돼요.
(줄 번호는 표시를 넣은 지금 기준이에요. 코드를 고치면 조금씩 밀릴 수 있어요. 그럴 땐 파일에서 구역 이름으로 찾으세요.)

## 이럴 땐 여기

- **"서버 오류가 났어요"** → [서버 입구·오류 처리] (src/index.js). Cloudflare 기록(로그)에서 진짜 오류를 같이 보기
- **가게 화면이 안 뜨고 "가게 정보를 불러오지 못했어요"** → 손님 화면 [시작·오류 처리] → 서버 [상품 목록]
- **결제 버튼을 눌렀는데 주문이 안 됨** → 손님 화면 [가상 결제] → 서버 [주문 받기·가상 결제] → [재고 계산]
- **주문은 됐는데 Slack·시트·노션에 안 뜸** → 서버 [알림] → integrations.js의 [알림]·[구글 시트]·[노션 기록]. 관리자 화면 '처리 기록'에 "연동: 실패 (...)" 이유가 적혀 있어요
- **품절인데 알림이 안 옴** → [재고 알림]
- **문의가 전부 "사람 확인 필요"로 들어옴** → [AI 문의 분류·답변 초안] (하루 한도인지, AI 오류인지 처리 기록의 'AI분류' 줄로 구분) → ai.js [오류 처리]
- **AI 답변이 엉뚱함·안내문과 다름** → src/policy.js [안내문(정책)] → src/ai.js [안내문(정책)]
- **관리자 로그인이 안 됨·막힘** → [관리자 로그인] (10번 틀리면 10분 잠금)
- **시연용에서 이름·연락처가 그대로 보임** → [시연용 가림]
- **아침 9시 보고서·재구매 안내가 안 옴** → src/jobs.js [매일 9시 보고서]·[재구매 안내] → [서버 입구·오류 처리]의 자동 실행
- **노션 상태가 안 바뀜** → [노션 상태 바꾸기]
- **메뉴를 눌러도 화면이 안 바뀜** → 각 화면 파일의 [화면 바꾸기]

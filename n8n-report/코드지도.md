# 코드지도 — 현장 진단 메모 → AI 보고서 (n8n)

오류가 나면 "○○ 부분에서 오류가 났어요"라고 말할 수 있게, 코드 안에 `// ===== [구역 이름] =====` 표시를 달아 뒀어요.
줄 번호는 2026-11-08 기준이에요. 코드를 고치면 조금씩 밀릴 수 있어요.

## n8n 흐름 (순서대로)

```
[현장 진단 입력] 폼 ─┐
                     ├→ [요청 만들기] → [AI에게 보고서 요청] → [보고서 만들기] ─┬→ [보고서 파일 저장]
[링크로 실행 (예시)] → [예시 고르기] ─┘                                          └→ [진단 대장에 기록] → [긴급인가?]
                                                                                       ├ 예 → [담당자 알림 (디스코드)] (꺼져 있음) ─┐
                                                                                       └ 아니요 ─────────────────────────────────┴→ [링크로 왔나?]
                                                                                                    ├ 예 → [링크에 보고서 돌려주기]
                                                                                                    └ 아니요 → [보고서 보여주기] (폼 화면)
```

| 순서 | 노드 이름 | 하는 일 | 고장 나면 보이는 증상 |
|---|---|---|---|
| 1 | 현장 진단 입력 | 폼에서 단지명·위치·메모·작성자를 받음 | 폼 주소가 안 열림, 404 (워크플로가 안 켜짐) |
| 1' | 링크로 실행 (예시) → 예시 고르기 | 링크만 열면 예시 1~3으로 실행 | 시연 페이지 "지금 바로 실행"이 "n8n에 연결하지 못했어요" |
| 2 | 요청 만들기 | 메모를 Claude에게 보낼 질문으로 묶음 (`request.js`) | 이 노드가 빨갛게 됨, 다음 노드로 안 넘어감 |
| 3 | AI에게 보고서 요청 | Claude API 호출 | 401(키 문제), 400(요청 모양 문제), 시간 초과(3분) |
| 4 | 보고서 만들기 | AI 답을 보고서 HTML + 대장 한 줄로 (`report.js`) | "AI 응답에 본문이 없어요", "처리하지 않았어요", JSON 오류 |
| 5 | 보고서 파일 저장 | `reports/진단보고서_….html` 저장 | reports 폴더에 새 파일이 안 생김 |
| 5 | 진단 대장에 기록 | `reports/진단대장.csv`에 한 줄 덧붙임 | 엑셀로 열어 둔 상태면 쓰기 실패 / 줄이 안 늘어남 |
| 6 | 긴급인가? | 급한 정도가 "긴급"인지 봄 | 긴급인데 알림 쪽으로 안 감 |
| 7 | 담당자 알림 (디스코드) | 긴급이면 디스코드로 알림 (지금은 꺼짐) | 켰는데 알림이 안 옴 (DISCORD_WEBHOOK_URL 없음) |
| 8 | 링크로 왔나? → 링크에 보고서 돌려주기 / 보고서 보여주기 | 들어온 길에 맞춰 보고서 화면을 돌려줌 | 실행은 끝났는데 화면이 계속 기다림, 빈 화면 |

## 이럴 땐 여기

- **"점검/401/인증" 오류, AI 노드가 빨강** → [AI 호출] build.mjs:110. ANTHROPIC_API_KEY가 n8n 켤 때 들어갔는지(start-n8n.ps1), 키 만료·크레딧부터 확인
- **AI 노드가 400 오류** → [요청 만들기] request.js:70 (모델 이름) 또는 [답 모양 정하기] request.js:24
- **"AI 응답에 본문이 없어요" / "처리하지 않았어요" / JSON 오류** → [AI 답 확인] report.js:7
- **보고서에 지어낸 숫자·가격이 나옴** → [AI 지시문] request.js:4
- **급한 정도가 이상함 / 긴급인데 알림이 안 감** → [급한 정도 판단] request.js:22, [알림 분기] build.mjs:172 (디스코드 노드는 원래 꺼져 있음)
- **reports 폴더에 파일이 안 생김** → [파일 저장] build.mjs:144, [파일 이름 정하기] report.js:18
- **진단대장.csv가 안 늘어남 / 엑셀에서 칸이 밀림** → 엑셀을 닫고 다시. [진단 대장(CSV)] build.mjs:158, report.js:89
- **폼 제출 뒤 화면이 계속 기다림** → [결과 돌려주기] build.mjs:213
- **시연 페이지 "지금 바로 실행"이 연결 실패** → n8n이 켜져 있는지(start-n8n.ps1). [링크 입구] build.mjs:76, [시연 페이지 만들기] make-demo.mjs:86
- **request.js / report.js를 고쳤는데 n8n에서 그대로임** → n8n 안 코드는 build.mjs가 JSON에 복사한 것. `node workflow/build.mjs` 뒤 다시 import 해야 바뀜

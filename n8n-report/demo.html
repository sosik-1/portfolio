현장 진단 메모 → AI 보고서 초안 (n8n 자동화)

현장 담당자가 짧은 메모만 남기면, n8n 워크플로가 AI로 진단 결과·추정 원인·급한 정도·권장 조치·작업 항목(견적)을 정리해 보고서 파일로 저장하고 진단 대장에 기록합니다. 아래는 미리 돌려 둔 예시예요.

흐름 폼 입력 → 요청 만들기 → AI 호출 → 보고서 만들기 → 파일 저장 + 진단 대장 기록 → 긴급인가? → 담당자 알림 → 결과 화면
규칙: 메모에 없는 수치는 "현장 실측 필요" · 원인은 "추정" · 단가는 비움(담당자가 채움)

햇살아파트 · 지하주차장 · 현장 담당자
지하 2층 B구역 천장 균열 4곳에서 물이 떨어지고 있음. 그중 1곳 아래 전기 배관함 있음. 기둥 2개 모서리 콘크리트 들뜸, 손으로 누르면 부스러짐. 바닥에 물 고임 약 3m 길이. 어제 비 온 뒤부터 심해졌다고 관리소장님이 말함.
→

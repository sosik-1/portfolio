(주)다온웍스 정보보안 수칙

※ 이 문서는 포트폴리오 시연용으로 지어낸 가상 회사의 수칙입니다. 실제 회사와 관계없습니다.

시행일: 2026년 2월 1일 / 관리 부서: 정보보안팀

1. 계정과 비밀번호

1-1. 비밀번호는 12자 이상으로 하고, 영문 대문자·소문자·숫자·특수문자 중 3가지 이상을 섞는다.
1-2. 비밀번호는 90일마다 바꾼다. 최근에 쓴 비밀번호 5개는 다시 쓸 수 없다.
1-3. 로그인에 5번 연속 실패하면 계정이 30분 동안 잠긴다. 급하면 IT헬프데스크(내선 2580)에 연락해 잠금을 풀 수 있다.
1-4. 사내 시스템에 밖에서 접속할 때는 2단계 인증(OTP 앱)을 반드시 쓴다.
1-5. 비밀번호를 동료에게 알려 주거나 메모지에 써서 붙여 두지 않는다.

2. 자리 비울 때

2-1. 자리를 비울 때는 화면을 잠근다(Windows 키 + L). 10분 동안 아무 입력이 없으면 화면이 자동으로 잠긴다.
2-2. 퇴근할 때는 책상 위에 서류를 두지 않고 잠금 서랍에 넣는다(클린 데스크).

3. 외부 저장장치

3-1. USB 메모리, 외장 하드 같은 외부 저장장치는 회사 PC에 기본적으로 쓸 수 없게 막혀 있다.
3-2. 업무상 꼭 필요하면 그룹웨어에서 '저장장치 사용 신청'을 하고 팀장과 정보보안팀의 승인을 받는다. 승인은 최대 30일 동안 유효하다.
3-3. 파일을 외부로 보낼 때는 사내 보안 파일 전송 시스템을 쓰고, 개인 이메일·개인 클라우드로 업무 파일을 보내지 않는다.

4. 재택근무와 외부 접속

4-1. 재택근무 중에는 회사 VPN에 접속한 뒤 사내 시스템을 쓴다.
4-2. 카페, 공항 같은 공용 와이파이에서는 VPN 없이 사내 시스템에 접속하지 않는다.
4-3. 회사 노트북을 가족이나 다른 사람이 쓰게 하지 않는다.

5. 메일과 메신저

5-1. 모르는 사람이 보낸 메일의 첨부파일이나 링크는 열지 않는다.
5-2. 의심스러운 메일을 받으면 열지 말고 security@daonworks.example 으로 전달해 신고한다.
5-3. 개인정보(주민등록번호, 계좌번호 등)는 메신저로 보내지 않는다. 꼭 보내야 하면 파일에 암호를 걸어 보안 파일 전송 시스템으로 보낸다.

6. 분실과 사고 신고

6-1. 회사 노트북, 휴대폰, 출입카드를 잃어버리면 알게 된 때부터 1시간 안에 IT헬프데스크(내선 2580)에 신고한다. 업무 시간이 아니면 보안 당직 휴대폰(010-0000-2580)으로 연락한다.
6-2. 신고를 받은 IT헬프데스크는 원격으로 기기를 잠그고 계정 비밀번호를 초기화한다.
6-3. 출입카드를 다시 발급받을 때 본인 잘못으로 잃어버린 경우에는 재발급 비용 1만 원을 낸다.

7. 입사와 퇴사

7-1. 새로 들어온 직원은 입사 후 7일 안에 온라인 정보보안 교육을 듣는다. 모든 직원은 1년에 한 번 정보보안 교육을 다시 듣는다.
7-2. 퇴사하는 직원의 계정은 마지막 근무일 18시에 막는다. 메일함은 30일 동안 보관한 뒤 지운다.
7-3. 퇴사자는 마지막 근무일에 노트북, 출입카드, OTP 기기를 IT헬프데스크에 반납한다.

8. 위반 시 조치

8-1. 이 수칙을 처음 어기면 정보보안팀이 경고하고 보안 교육을 다시 듣게 한다.
8-2. 1년 안에 2번 넘게 어기거나 회사 정보가 밖으로 새어 나간 경우에는 인사위원회에 넘긴다.

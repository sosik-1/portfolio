# 코드 지도

코드 안에 `===== [구역 이름] =====` 표시를 붙여 두었어요.
무언가 고장 나면 아래 표에서 증상을 찾고, "○○ 부분에서 오류가 났어요"라고 구역 이름으로 말하면 돼요.
파일에서 구역 이름(예: `[검색]`)으로 찾기(Ctrl+F)를 하면 바로 그 자리로 가요.

줄 번호는 2026-11-08 기준이에요. 코드를 고치면 조금씩 밀릴 수 있어요.

### 이럴 땐 여기 (규정 Q&A)

- 파일을 올렸는데 "글자를 거의 찾지 못했어요" → [PDF 글자 뽑기] (스캔 이미지 PDF는 원래 못 읽어요)
- 올릴 때 "문서를 검색용으로 바꾸는 중 오류가 났어요" → [임베딩] (src/search.js:83, src/index.js:113)
- 올릴 때 "문서가 너무 길어요" → [설정값] 한도 / [설정값] 조각 길이
- "오늘 사이트 전체 올리기 한도를 다 썼어요" / "오늘 질문 한도를 다 썼어요" → [저장(DB): 사용량 세기], [설정값]
- 질문마다 "문서에서 찾지 못했어요" → [검색], [저장(DB): 볼 수 있는 조각 불러오기]
- "AI 호출 오류 (401)" → [Claude 부르기]: API 키 확인 / (429) 너무 많이 부름·크레딧 / (5xx) Anthropic 쪽 문제
- "서버에 AI 키가 설정되지 않았어요" → [AI 답변 만들기: 묻기 전체 흐름] (Cloudflare 비밀값 ANTHROPIC_API_KEY)
- "AI 답 형식 오류" → [답 모양 정하기], [AI 답 읽기]
- "원문에서 근거 문장을 확인하지 못해 보여주지 않아요"가 자주 뜸 → [근거 문장 대조]
- 근거를 눌렀는데 창이 안 뜨거나 비어 있음 → [근거 조각 창 열기], [근거 조각 보기]
- 그냥 "서버 오류가 났어요" → [오류 처리] (src/index.js:218). Cloudflare 로그에서 '서버 오류:' 줄을 보면 어느 구역인지 나와요

### 이럴 땐 여기 (검수 에이전트)

- "청구서 내용을 붙여 넣거나 사진을 올려 주세요" / "사진은 5MB 이하…" → [검수 받기], [사진 읽기]
- "오늘 검수 한도를 다 썼어요" → [설정값] 하루 검수 한도, [검수 받기]
- 모든 검수가 "서버 오류가 났어요" → [Claude 부르기](claude.py). 로그에 ClaudeError 401이면 키, 429면 한도·크레딧
- "AI가 이 문서 검수를 거절했어요" → [오류 처리: AI가 거절]
- "에이전트가 결과를 기록하지 못했어요" → [에이전트 반복](12번 넘음), [도구: 기록(DB·시트)]
- 단계 목록에 "규정 검색 실패" → [도구: 규정 찾기], [도구: 규정 찾기 연결] → 1부의 [검색만 하기]·[검색]까지 이어서 보기. /api/rules?q=택시 로 먼저 확인 (AI 0원)
- 단계에 "quote가 … 일치하지 않아요"가 반복 → [근거 문장 대조] (tools.py:275)
- 요일·공휴일 판정이 틀림 → [도구: 날짜 계산], [설정값] 공휴일
- 견적서 금액 판정이 틀림 → [도구: 금액 계산]
- "이번 달 몇 번" 같은 횟수 판정이 틀림 → [도구: 과거 내역(SQL)]
- 시트 칸이 "-" (시트에 안 들어감) → [구글 시트 보내기], [연결 확인: 구글 시트]
- 위반·보완인데 Slack이 안 옴 → [Slack 보내기], [연결 확인: Slack]
- 시트의 '상세 보기' 링크가 "없는 기록이에요" → [검수 기록 한 건 보기], [기록 한 건 열기]
- 위쪽 통계 숫자가 비어 있음 → [보고서(SQL)], [통계·최근 기록]

문제가 생기면 아래 표에서 증상을 찾고, "○○ 부분에서 오류가 났어요"라고 구역 이름으로 말하면 돼요.
(줄 번호는 2026-11-08 기준. 코드를 고치면 조금씩 밀릴 수 있어요. 파일에서 `[구역 이름]`으로 찾으면 가장 정확해요.)

## 이럴 땐 여기

- **Slack에 알림이 안 옴** → [알림 · Slack] (integrations.js), 그다음 [알림] (index.js). 관리자 화면 처리 기록의 "연동" 줄을 먼저 보세요
- **구글 시트에 줄이 안 생김** → [알림 · 구글 시트]
- **노션에 새 접수가 안 생김** → [알림 · 노션]
- **노션에서 상태를 바꿨는데 관리자 화면이 그대로** → [노션 상태 맞추기 · 노션 → DB], [노션 상태 맞추기] (index.js, 1분마다 실행)
- **관리자 화면에서 상태를 바꿨는데 노션이 그대로** → [노션 상태 맞추기 · 관리자 → 노션], [관리자 수정]
- **모든 접수가 "AI 분류 실패" / "AI 호출 오류"** → [오류 처리] (classify.js) — API 키·크레딧부터 확인, 그다음 [AI 분류]
- **모든 접수가 "한도 초과 - 사람 확인 필요"** → [하루 한도]
- **AI 판단(종류·급한 정도)이 자꾸 틀림** → [AI 지시문]
- **담당 팀이 틀림** → [담당 팀 표]
- **접수하기 버튼을 눌러도 실패** → 화면: [접수 보내기] / 서버: [접수 받기], [접수 받기 · 입력 검사], [저장(DB)]
- **"서버 오류가 났어요"** → [서버 입구 · 오류 처리] (Cloudflare 로그에 실제 원인이 찍혀요)
- **관리자 로그인이 안 됨 / 막힘** → [관리자 로그인] (index.js·admin.html 둘 다)
- **관리자 목록·통계가 비어 있음** → [관리자 화면 목록], [통계]
- **시연용 화면에 실명·전화번호가 보임** → [시연용 가림], Slack·노션이면 [개인정보 가림]
- **사진이 안 올라감** → [사진 고르기], [접수 받기 · 입력 검사]

실제 운영 때 지키는 것

  1. 이름·연락처는 다른 칸으로 받기문의 양식에서 이름·연락처 칸을 내용 칸과 나눠 받고, AI에는 내용 칸만 보내요.
  2. 내용에 섞인 연락처도 가리기"010-…로 연락 주세요"처럼 본문에 적힌 번호·이메일·주민번호도 보내기 전에 바꿔요.
  3. 이름은 병원 명단과 맞춰 가리기글만 보고 이름을 짐작하지 않고, 예약 명단에 있는 이름만 [환자1]로 바꿔요.
  4. n8n 실행 기록 저장 끄기원문이 자동화 도구 안에 쌓이지 않게, 끝나자마자 지우도록 설정해요.
  5. 학습에 쓰지 않는 요금제 쓰기보낸 글이 AI 학습에 쓰이지 않는 API 요금제를 쓰고 보관 기간도 확인해요.
  6. 의학적 판단은 하지 않기AI는 증상을 판단하지 않고, 수술 후 증상을 간호팀에 알리는 데까지만 해요.
  7. 의료광고 규정 지키기전후 사진·할인·체험단 문의에는 주의 표시를 붙이고 내원 상담으로 안내해요.
시안 화면이에요. 병원·환자 이름과 번호는 모두 지어낸 예시예요. 분류 결과는 미리 적어 둔 것이고, 개인정보 가리기는 실제 버전과 같은 코드로 이 화면에서 돌아가요.

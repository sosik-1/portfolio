## 공통으로 지킨 것
- **숫자로 확인**: 정답을 적은 시험 데이터로 정확도·속도·비용을 재고, 틀린 것을 하나씩 열어 보고 고쳤어요.
- **실패할 때를 먼저**: AI가 실패해도 접수는 받고, 모르면 "찾지 못했어요"·"?"로 남겨요.
- **AI는 판단, 정확한 일은 코드**: 날짜·금액 계산, 부서 배정, 개인정보 가리기는 코드가 해요.
- **사람이 확정**: 답변 발송·최종 승인은 사람이 해요.
- **코드 지도**: 폴더마다 `코드지도.md`가 있어서 "이 증상이면 이 파일·구역"을 쉬운 말로 찾을 수 있어요.

## 만든 방식
코드는 AI 코딩 도구(Claude Code)로 작성했고, 문제 정의·설계·판단 기준·시험 데이터·배포와 장애 대응은 직접 했어요.
API 키와 비밀번호는 코드에 넣지 않고 환경변수·Cloudflare 비밀값으로만 써요. 예시에 나오는 회사·사람 이름과 번호는 모두 지어낸 것이에요.
